이럴 땐

"알림 못 봤어요"

재호출 누르면 알림이 한 번 더 가고 20분이 다시 시작됩니다.

폰 없는 손님 (어르신·아이)

대리 접수 → 이름이나 특징(빨간 모자) 입력. 알림이 안 가니 번호를 직접 불러 주세요.

접수 시간 · 오늘 끝 · 기기 고장

테크놀이터는 운영 14:00~20:00, 대기 접수는 매일 12:00~20:00에만 받습니다(그 전엔 손님 화면에 "대기 접수 : 12:00~"). 일찍 열려면 상단 접수 오픈 — 그날은 시간 설정보다 우선합니다. 잘못 눌렀으면 오픈 취소(예정 시각으로 되돌림, 접수된 손님 유지). 오늘 더 안 받을 땐 접수 마감(자정에 자동으로 풀림), 잠시 멈출 땐 일시중단 → 접수 재개. 쿠킹은 같은 자리의 예약 오픈/예약 마감이 예약에 적용됩니다.

잘못 눌렀다

아래 "오늘 처리 내역" ▼ 펼치기 → 호출로 복구 또는 대기로 복구. 원래 자리로 돌아갑니다.

순서를 바꿔 불러야 할 때그 팀 카드의 호출을 누르면 됩니다. 입장한 손님에게 노쇼·호출은 눌러도 안 들어갑니다. 아래 "오늘 처리 내역"에서 호출로 복구를 먼저 누르세요.
