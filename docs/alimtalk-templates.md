# 카카오 알림톡 템플릿 등록 (NCP SENS) — 11종

⚠️ **AlimTalk Template 메뉴에 등록한다.** BrandMessage Template(친구톡 계열)에 넣으면 카카오 검수가 없어 "정상"으로만 뜨고, 알림톡 API 발송 시 수신코드 `3015(템플릿을 찾을 수 없음)`이 난다 (2026-10-13 실제 발생).

경로: NCP 콘솔 → SENS → Biz Message → **AlimTalk Template** → 템플릿 등록

**모든 템플릿 공통(한 번만 읽기):** 채널 `@플릿_flit` / 메시지 유형 기본형 / 강조 유형 기본형 / 보안 미설정 / **버튼 사용 → 사용**, 웹링크(WL) 1개, **PC URL 비움** / 변수 `#{…}` 그대로 복붙.
템플릿 코드는 영문·숫자만(언더스코어 불가), 이름은 공백·괄호 없이.

등록 11개 끝나면 전부 체크 → **검수 요청** (등록만으로는 검수 안 들어감). 영업일 2~3일.
