# 카카오 알림톡 템플릿 등록용 (NCP SENS) — 11종

NCP 콘솔 → SENS → 프로젝트 → Biz Message → 템플릿 → **템플릿 등록**. 아래 11개를 하나씩 등록한다 (복붙).

공통 입력값:
- 채널: 플릿
- **템플릿 코드**: 아래 표의 코드 그대로 (예: `FLIT_Q01`) — 승인 후 이 코드를 DB `templates.ncp_template_code` 에 넣는다
- 카테고리: `서비스이용 > 이용안내/공지` (예약 계열은 `예약/신청 > 예약완료`·`예약알림` 선택 가능)
- 메시지 유형: 기본형 / 강조 유형: 선택 안 함 / 보안 템플릿: 아니오
- 버튼: 유형 **웹링크(WL)**, 버튼명·Mobile URL·PC URL 은 아래 값 (URL 안의 `#{token}`·`#{부스slug}` 는 변수 그대로 입력)
- 변수는 `#{한글}` 형식 그대로 — 카카오는 한글 변수명 허용

## 치환 변수 설명 (심사 '변수 설명'란에 붙여넣기)

| 변수 | 예시값 |
|---|---|
| #{행사명} | 2026 성남테크아트페스티벌 탄천마켓 |
| #{부스명} | 테크놀이터 1 |
| #{이름} | 홍길동 |
| #{대기번호} | 23 |
| #{앞대기수} | 4 |
| #{유효시간} | 5 |
| #{일시} | 10. 24. (토) 14:00 |
| #{장소} | 탄천마켓 쿠킹존 |
| #{인원} | 2 |
| #{token} | a1b2c3d4e5f6 (대기표 고유 식별자) |
| #{부스slug} | tech-1 (부스 식별자) |

## 1. FLIT_Q01 — 대기 접수 완료

- 템플릿 코드: `FLIT_Q01`
- 템플릿명: `플릿 대기 접수 완료`

**본문 (복붙):**
```
[#{행사명}] 대기 접수 완료

#{이름}님, #{부스명} 대기 접수가 완료되었습니다.

■ 대기번호: #{대기번호}번
■ 내 앞 대기: #{앞대기수}팀

순서가 가까워지면 다시 알려드립니다.
실시간 대기 현황은 아래 버튼에서 확인하세요.
```

**버튼:** 웹링크 · 버튼명 `대기 현황 보기` · URL `https://wait.flitunion.com/t/#{token}` (Mobile/PC 동일)

## 등록 후
승인되면 템플릿 목록에서 코드 확인 → 나(클로드)한테 "승인됐어" → 내가 `templates.ncp_template_code` 매핑하고 테스트 발송.
반려가 나면 사유 그대로 보내줘 (보통 '광고성 문구'·'변수 설명 부족'·'버튼 URL 형식').
