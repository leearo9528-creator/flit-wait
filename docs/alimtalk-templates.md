# 카카오 알림톡 템플릿 등록 (NCP SENS) — 11종

⚠️ **AlimTalk Template 메뉴에 등록한다.** BrandMessage Template(친구톡 계열)에 넣으면 카카오 검수가 없어 "정상"으로만 뜨고, 알림톡 API 발송 시 수신코드 `3015(템플릿을 찾을 수 없음)`이 난다 (2026-10-13 실제 발생).

경로: NCP 콘솔 → SENS → 프로젝트 → Biz Message → **AlimTalk Template** → 템플릿 등록

## 공통 입력값

| 항목 | 값 |
|---|---|
| 채널 ID | `@플릿_flit` |
| 템플릿 코드 | 아래 표의 코드 **그대로** — 영문·숫자만 허용(언더스코어·한글 불가). DB `templates.ncp_template_code`와 일치해야 발송된다 |
| 템플릿 이름 | 아래 표 — 한글·영문·숫자만 (공백·괄호 피함) |
| 카테고리 | 서비스이용 > 이용안내/공지 (R계열은 예약/신청 > 예약완료·예약알림 가능) |
| 메시지 유형 | 기본형 |
| 강조 유형 | 기본형 |
| 보안 설정 | 미설정 |
| 버튼 사용 | **사용** → 웹링크(WL) 1개, **Mobile URL만 입력, PC URL 비움** (발송 코드가 linkMobile만 보내므로 PC를 넣으면 불일치) |
| 변수 | `#{한글}` 형식 그대로 복붙 |

등록 후 11개 전부 체크 → **검수 요청** (등록만으로는 검수가 시작되지 않는다). 카카오 검수 영업일 2~3일.

## 등록 후

1. 11개 체크 → **검수 요청**
2. DB 매핑: `update templates set ncp_template_code = 'FLIT' || code;` (코드 표와 동일하게 — 승인 전에 넣어둬도 무방, 승인되면 바로 발송됨)
3. 승인 후 테스트: `select join_queue('t-tech-1','아로','010-2244-3585',1,true);` → 1분 내 발송 → NCP 발송 결과에서 수신 코드 확인
4. 반려 시 사유 그대로 공유 (보통 '광고성 문구'·'변수 설명 부족'·'버튼 URL 형식')
