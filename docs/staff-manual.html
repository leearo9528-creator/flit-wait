부스 　　　　　　　　　

① 아침에 — 로그인

  1. 폰에서 스태프 주소 열기 wait.flitunion.com/s/　　　　
  2. PIN 입력 　　　 → 입장
  3. 홈 화면에 추가해두면 다음부터 바로 열림
  4. 보조배터리 연결 · 화면 자동잠금 끄기

② 손님이 접수하는 법

  1. 부스 앞 QR 찍기 → 이름·전화·인원 → 대기 접수
  2. 대기번호와 앞 팀 수가 손님 폰에 뜸
  3. 차례가 가까우면 카톡 알림, 호출하면 카톡 + 폰 진동
폰 없는 손님 → 대리 접수 버튼으로 이름만 넣고 번호를 불러줌

③ 운영 중 — 버튼 4개만 기억

다음 호출맨 앞 팀을 호출. 손님 폰에 "지금 입장하세요" 알림이 감. 자리 날 때마다 한 번씩 누르면 끝.
입장손님이 왔을 때. 손님 폰의 대기번호 화면을 확인하고 누름.
노쇼호출 후 5분이 지나도 안 오면. 안 눌러도 시간이 지나면 자동 노쇼됨. 손님이 늦게 오면 다시 접수하게 안내.
재호출손님이 알림을 못 받은 것 같을 때 한 번 더 보냄.
예약 부스는 오늘 회차 탭 → 손님 이름 옆 체크인. 시작 10분 뒤까지 안 온 예약은 자동 취소되고 빈 자리는 현장 대기 1순위에게 자동으로 호출됨.

④ 이럴 땐

  • 재료 소진·우천·휴식 → 상단 접수 일시중단. 손님 화면에 바로 "일시중단" 표시. 재개도 같은 버튼.
  • 폰이 죽음 → 다른 폰에서 같은 주소 + 같은 PIN. 데이터는 다 서버에 있어 그대로 이어짐.
  • 잘못 눌렀어요 → 호출을 잘못했으면 대기로, 노쇼를 잘못 눌렀으면 운영본부에 연락 (복구 가능).
  • 손님 "알림 안 와요" → 손님 폰에서 접수 때 받은 화면(또는 카톡 링크)을 열면 자동으로 갱신됨. 재호출 한 번.
  • 앱 자체가 안 열림(통신 장애) → 종이 번호표로 전환, 운영본부에 즉시 연락. 복구되면 대리 접수로 순서 맞춤.

⑤ 꼭 지켜주세요

  • 손님 전화번호를 입으로 부르거나 적어두지 않기 (화면엔 뒤 4자리만 보임)
  • 대기 순서는 시스템 순서대로. 지인 끼워넣기 금지
  • 호출했는데 안 보이면 큰 소리로 번호 한 번 더 부르고 노쇼 처리
  • 퇴근 전 로그아웃 안 해도 됨 (다음 날 그대로 사용)
